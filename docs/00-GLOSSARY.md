# 术语表：文里这些写法是什么意思

正文里不可避免地留下了些作者本机的写法。看到不认识的先来这里查，查不到就当普通技术词理解。

## 一、占位符（换成你自己的）

| 文中写法 | 意思 |
|---|---|
| `<工作区>` | 你放项目的根目录，例：`D:\work`、`E:\projects` |
| `%USERPROFILE%` | Windows 用户目录（`C:\Users\你的名字`） |
| `<主机名>` / `<用户名>` | 你电脑的名字、你的账号名 |
| `<VMUSER>` / `<VM>` | 虚拟机的用户名、虚拟机名 |
| `<内网IP>` | 局域网或虚拟组网里的地址，不是公网 IP |
| `<项目>` / `<角色>` | 作者自己项目里的名字与角色名，已替换 |
| `<VBox 目录>` 等 | 某个软件安装目录的占位 |

原则：文里所有具体路径都做成了占位符，照着替换成你自己的，不要照抄。

## 二、"出处"里的写法（别去找，按内容理解）

| 写法 | 意思 |
|---|---|
| `NN 号 §x.y` / `手册 35` | 作者本机的第 NN 号笔记、第 x.y 节 |
| `_归档/…` | 作者把过期件挪去的归档目录 |
| `事故/…`、`审计/…`、`VM往返/…` | 作者本机按用途分的子目录 |
| 一个短编号加"当前态" | 作者那份"活跃任务与待办"的滚动文档，编号不用记 |

保留它们的唯一目的是每条坑可追溯来源。你不需要那些文件。

## 三、作者那套文档体系的叫法（原理见 [06](06-keeping-the-work.md) §2）

| 词 | 意思 |
|---|---|
| 正本 | 某条事实唯一权威的那一处（Single Source of Truth） |
| 派生稿 | 从正本生成或摘编的副本，例：这份对外文档 |
| 真相源 | 同上，强调"哪句算数"只能有一处 |
| 热记忆 / 记忆空间 | 作者自己搭的分层笔记，机制细节不在本仓，按"不同粒度的笔记"理解 |
| 台账 | 变更记录：什么时候改了什么、为什么 |
| 时效声明 | 给可能过期的文档加的一行标注，带日期 |

## 四、反复出现的黑话

| 词 | 一句话意思 |
|---|---|
| 假成功 | 工具说做成了，其实没做，常因为根本没查到 |
| 假失败 | 报"坏了"，其实东西是好的，问题在检查器 |
| 证据四形态 | 文件、命令输出、截图（人看过）、断言，缺哪种补哪种 |
| 判据 | "怎么算做成了"的可复核标准；写不出反例的判据通常是假判据 |
| 反例 | "如果这件事是错的，我会看到什么" |
| 迭代止损线 | 评审返工循环满两轮就必须停下问人，不许自行加固 |
| 缓存重读 | 长会话里把累积上下文重新发一遍，通常占大头成本 |
| junction（目录联接） | Windows 的目录快捷方式；删它和删真身是两回事 |
| BOM | 文件开头三个看不见的字节，会让某些脚本出错 |
| CRLF / LF | 换行的两种存法；`.bat`、`.cmd` 必须 CRLF |
| 截断 | 大文件没下完却看起来下完了，所以必须校验 |
| 脱敏 | 把会暴露身份或机器的内容替换掉，再对外 |
