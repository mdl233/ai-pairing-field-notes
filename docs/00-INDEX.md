# 索引：从"我遇到什么"找到"该看哪篇"

> **这篇是跨篇导航** —— 六篇加起来 20 万字，但你通常只想知道**某一件事**该怎么办。
> **三种找法**：① **看到怪现象** → 看下面的「症状索引」；② **想做某件事** → 看「场景索引」；③ **记得某个词** → 看「关键词表」。
> **时效**：复核 **2026-10-08**；带 🔄 的条目会随环境变化，用前请按文中命令复核（其余条目自带日期与出处）。
> **找不到时**：先看 `01` 的 **§一 速查表**（91 行，专治"报错看不懂"），再回来查关键词。

## 四、怎么读文中的"出处"

正文条目末尾常写着 `NN 号 §x.y`、`_归档/…`、`事故/…` —— 那是**作者本机内部笔记的编号与路径**。
**保留它们是为了"每条坑都可追溯"；你按内容理解即可，不必去找那些文件。**（详见 [`00-GLOSSARY.md`](00-GLOSSARY.md)）
