# 索引：从"我遇到什么"找到"该看哪篇"

六篇加起来二十万字，通常你只想知道某一件事该怎么办。三种找法：

1. 看到怪现象，看下面的症状索引。
2. 想做某件事，看场景索引。
3. 记得某个词，看关键词表。

找不到时，先看 `01` 的速查表（97 行，专治报错看不懂），再回来查关键词。

## 四、怎么读文中的"出处"

条目末尾常写 `NN 号 §x.y`、`_归档/…`、`事故/…`，那是作者本机内部笔记的编号与路径。保留是为了每条坑可追溯，按内容理解即可，不必去找那些文件（详见 [00-GLOSSARY](00-GLOSSARY.md)）。
